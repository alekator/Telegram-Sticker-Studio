# Редактор статических изображений M1.2

Выберите одно импортированное статическое изображение и нажмите **Edit selected image**. В редакторе доступны кисть, ластик, слои, Undo/Redo, колесо для масштаба, средняя кнопка для перемещения и Fit. Save добавляет изменения в текущий проект; при возврате изменения также добавляются автоматически. Чтобы сохранить их на диск, используйте Save проекта в галерее.

Схема проекта версии 2 сохраняет оригинальные ссылки и относительные ссылки на отдельные файлы ImageSpace в каталоге `<имя проекта>.assets`. Переносите этот каталог вместе с JSON и исходниками. Сохранение сначала записывает новые файлы с именами по SHA-256, затем заменяет JSON; предыдущая версия проекта продолжает ссылаться на прежние файлы при неудачном сохранении. Save as создаёт собственный каталог документов. Старые проекты схемы 1 открываются без миграции на месте и записываются как версия 2 при следующем сохранении. Неиспользуемые старые файлы каталога автоматически не удаляются.

Исходник не изменяется. Изменения сохраняются как редактируемый документ ImageSpace, а не последовательность полностью параметрических мазков; Undo/Redo действует в открытой сессии. GIF и видео сохраняют существующий просмотр и в этом редакторе не открываются. Текущие ограничения: фиксированные цвет и размер кисти, полная перерисовка, синхронное создание миниатюры, ручная проверка всех трёх ОС и производительности больших документов ещё нужна. ImageSpace 0.3.2-alpha.1 — предварительная версия. Лицензия: [MIT](IMAGESPACE-LICENSE.txt); исходный [репозиторий](https://github.com/wieslawsoltes/ImageSpace/tree/123d26e318f26f613a68cb1dcd89199619670106).

Базовый CPU-замер Windows Release (`GraphicsPerformanceTests`, 20 кадров, изменение одного пикселя, вне UI): 512×512/2 слоя — медиана 2,36 мс, P95 2,52 мс, 71 287 байт управляемых выделений на кадр; 2048×2048/4 слоя — 58,45 мс, P95 69,64 мс, 251 394 байта на кадр. Прирост private memory за замер — 1 150 976 и 7 020 544 байта соответственно. Значения зависят от машины, не включают обработку ввода и показ окна и не подтверждают отсутствие утечек.
