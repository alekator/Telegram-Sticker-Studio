# Редактор статических изображений M1.2

Выберите одно импортированное статическое изображение и нажмите **Edit selected image**: редактор откроется внутри главного окна. В нём доступны кисть, ластик, слои, Undo/Redo, колесо для масштаба, средняя кнопка для перемещения и Fit. **Apply to project** переносит правки в открытый проект в памяти; **Save project** записывает на диск только уже применённые изменения. Обе команды доступны в редакторе. Если сохранить проект при наличии неприменённых изменений, они останутся в редакторе и сообщение напомнит применить их перед следующим сохранением.

Кисть и ластик выбираются слева или клавишами **B** и **E**. Справа доступны независимые настройки размера (1–200 px), непрозрачности кисти / силы ластика и жёсткости. Цвет кисти задаётся палитрой или полем `#RRGGBB`; некорректное значение не применяется. Предпросмотр показывает цвет, непрозрачность и условно масштабированный размер, а не точный отпечаток кисти. Настройки действуют в текущей сессии редактора и не записываются в проект. При активном вводе в поле клавиши инструментов не перехватываются.

**Back to gallery** возвращает к галерее. При возврате или закрытии приложения с неприменёнными изменениями выберите **Apply changes**, **Discard changes** или **Continue editing**. Отмена правок касается только изменений после последнего применения. При неудачном применении редактор остаётся открытым; при ошибке сохранения проекта применённые изменения остаются в памяти, чтобы можно было повторить сохранение. Применённые, но не сохранённые на диск изменения защищены существующим подтверждением выхода из проекта.

Схема проекта версии 2 сохраняет оригинальные ссылки и относительные ссылки на отдельные файлы ImageSpace в каталоге `<имя проекта>.assets`. Переносите этот каталог вместе с JSON и исходниками. Сохранение сначала записывает новые файлы с именами по SHA-256, затем заменяет JSON; предыдущая версия проекта продолжает ссылаться на прежние файлы при неудачном сохранении. Save as создаёт собственный каталог документов. Старые проекты схемы 1 открываются без миграции на месте и записываются как версия 2 при следующем сохранении. Неиспользуемые старые файлы каталога автоматически не удаляются.

Отсутствующий оригинал отмечается в галерее; восстановите файл по указанному пути. Если отсутствует каталог `.assets` или файл редактируемого документа, проект не открывается и показывается путь к отсутствующему файлу. Если документ ImageSpace повреждён, соответствующий стикер отмечается в галерее, а редактор не заменяет его исходным изображением. Сохранённый проект и исходник при этих ошибках не перезаписываются.

Исходник не изменяется. Изменения сохраняются как редактируемый документ ImageSpace, а не последовательность полностью параметрических мазков; Undo/Redo действует в открытой сессии. GIF и видео сохраняют существующий просмотр и в этом редакторе не открываются. Текущие ограничения: полная перерисовка, синхронное создание миниатюры, ручная проверка всех трёх ОС и производительности больших документов ещё нужна. ImageSpace 0.3.2-alpha.1 — предварительная версия. Базовый CPU-замер Windows Release (`GraphicsPerformanceTests`, 20 кадров, изменение одного пикселя, вне UI): 512×512/2 слоя — медиана 2,36 мс, P95 2,52 мс, 71 287 байт управляемых выделений на кадр; 2048×2048/4 слоя — 58,45 мс, P95 69,64 мс, 251 394 байта на кадр. Прирост private memory за замер — 1 150 976 и 7 020 544 байта соответственно. Значения зависят от машины, не включают обработку ввода и показ окна и не подтверждают отсутствие утечек.
