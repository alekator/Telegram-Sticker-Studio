# Зависимости и лицензирование

Исследовано 2026-11-22. Декларации пакетов и фактические транзитивные/native-зависимости нужно повторно проверять на конкретных версиях перед поставкой. Файл не является юридическим заключением.

| Компонент | Статус |
| --- | --- |
| [.NET 10](https://dotnet.microsoft.com/en-us/platform/support/policy/dotnet-core) | LTS до 14 ноября 2028; установленный SDK следует обновлять исправлениями безопасности. |
| [Avalonia.Desktop 12.1.6](https://www.nuget.org/packages/Avalonia.Desktop) и Fluent 12.1.6 | MIT; пакет рассчитан на .NET 8 и совместим с более поздними целями по данным NuGet. Используется в M0. |
| [CommunityToolkit.Mvvm 8.4.2](https://www.nuget.org/packages/CommunityToolkit.Mvvm) | Совместимость с .NET 10 указана NuGet; MIT. Планируется, не подключён. |
| [SkiaSharp 4.157.0](https://www.nuget.org/packages/SkiaSharp) | MIT; NuGet указывает совместимость с .NET 10. Native assets и возможное совпадение версий с Avalonia проверить при подключении. |
| [xUnit v3](https://www.nuget.org/packages/xunit.v3) | Актуальная ветка; шаблон SDK создал v2, который NuGet отмечает как legacy. Пересмотреть до появления существенных тестов. |
| [ImageSharp](https://sixlabors.com/pricing/) | Коммерческое лицензирование зависит от условий; не включён. |
| [FFmpeg](https://ffmpeg.org/legal.html) | LGPL 2.1+ по умолчанию, необязательные GPL-компоненты меняют условия. Конкретная сборка не выбрана и не поставляется. Проверить configure flags, исходники, уведомления, возможность замены и лицензии всех зависимостей; запретить nonfree-конфигурации без отдельного решения. |
| [libvpx](https://github.com/webmproject/libvpx/blob/main/LICENSE) | Отдельная лицензия и патентные условия проекта; проверить конкретную версию, сборку, уведомления и применимость VP9 перед распространением. |

Для финальных пакетов нужен полный инвентарь лицензий и исходников всех транзитивных компонентов, проверка каждой платформы и выполнения условий распространения. Патентные вопросы не решаются одной проверкой лицензии исходного кода.

Включение компонента в дистрибутив или его разовая загрузка через будущий Dependency Manager не отменяют лицензионных обязательств. Для каждого распространяемого или предлагаемого к загрузке бинарного файла необходимо заранее зафиксировать происхождение, версию, лицензию, условия источников и уведомлений, платформу, доверенный URL и SHA-256. Конкретная поставка FFmpeg и libvpx пока не утверждена; наличие ссылки на проект не подтверждает право распространять произвольную сборку.
