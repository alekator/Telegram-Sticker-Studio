# Архитектура

StickerForge работает локально: Avalonia (`StickerForge.Desktop`) управляет галереей, импортом, выбором папки и отображением прогресса; `StickerForge.Media` декодирует изображения и экспортирует статические WebP через SkiaSharp. `StickerForge.Core` хранит порядок и ссылки на исходники, `StickerForge.Infrastructure` сохраняет JSON-проекты версии 1. Создавать проект для обычного экспорта не требуется.

Экспорт запускается в фоновом потоке, проверяет содержимое PNG/JPEG/WebP, обрабатывает ошибки отдельных файлов и поддерживает отмену между операциями декодирования и кодирования. Результат записывается во вновь созданную папку; исходники и существующие файлы не перезаписываются. На прозрачный холст 512×512 помещается пропорционально масштабированное изображение, WebP кодируется с последовательным снижением качества до 512 КиБ. Если ограничение не достигнуто, файл исключается и ошибка попадает в отчёт.

В приложении нет Telegram API, аккаунтов, аналитики, облака и графического редактора. Выгруженные файлы пользователь самостоятельно загружает через Telegram. Для просмотра видео сохранён существующий локальный FFmpeg, который не требуется для экспорта статических изображений.
