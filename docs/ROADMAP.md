# Дорожная карта

Текущий этап: простая локальная подготовка статических стикеров — пакетный импорт, галерея, проекты M1.1 и экспорт пронумерованных WebP в отдельную папку.

До публичного релиза: проверить интерфейс и реальные файлы на Windows, macOS и Linux, производительность больших наборов, доступность и готовность self-contained дистрибутивов. Текущие тесты не заменяют проверку загрузки подготовленных файлов пользователем в Telegram.
