# ADR 0001: архитектурные границы

Статус: принято для M0, 2026-11-22.

Решение: .NET 10 LTS и Avalonia для desktop, независимый Core и порты Application. Рендеринг и медиа — отдельные адаптеры; правила Telegram версионируются отдельно. Проекты создаются сейчас, функции добавляются по мере появления проверяемых сценариев.

Причины: кроссплатформенность, независимость логики от UI, тестируемость и возможность других оболочек. Монолит проще в начале, но смешивает UI и native-медиа; web/Electron добавляет другой runtime и не соответствует выбранному стеку.

Последствия: контракты потребуют проверки, native-библиотеки и дистрибутивы проверяются на каждой платформе. Мобильная поддержка не подтверждена.
