# Спецификация продукта

Бесплатный desktop-инструмент: проект, импорт медиа, недеструктивное редактирование, порядок и emoji, проверка и локальный экспорт. Без обязательной авторизации, телеметрии, облака и AI. Публикация — возможная будущая отдельная online-функция.

При первой установке или запуске разрешена однократная загрузка необходимых компонентов. После их установки создание, сохранение и открытие проектов, импорт изображений, GIF и видео, редактирование изображений, слои, маски, эффекты, видео и анимация, пакетная обработка и экспорт стикерпаков должны полноценно работать без сети. Это требование к готовому продукту, а не обещание реализованных возможностей M0.

Цели: Windows x64 и по возможности ARM64, macOS Intel и Apple Silicon, Linux x64. Мобильный перенос возможен архитектурно, но не гарантирован. Self-contained сборки предпочтительно включают runtime и обязательные разрешённые native-компоненты; для крупных или необязательных компонентов предусмотрен Dependency Manager.

M0 — основа без фиктивных функций. M1 — рабочий сквозной сценарий. Дальнейшие этапы: слои, маски, анимация и профессиональные сценарии.
