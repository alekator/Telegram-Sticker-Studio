# Спецификация продукта

StickerForge — локальное настольное приложение для пакетной подготовки готовых PNG, JPEG и статических WebP к ручной загрузке в Telegram. Пользователь импортирует файлы и папки, сортирует и удаляет элементы, задаёт название и выбирает выходную папку. Проект можно сохранять, но это необязательно.

Экспорт создаёт новую папку с пронумерованными статическими WebP 512×512, сохраняя пропорции и прозрачность. При необходимости качество снижается, чтобы файл укладывался в 512 КиБ. Отмена и ошибки отдельных файлов отображаются пользователю; исходники остаются неизменными.

Приложение не отправляет медиа в интернет и не содержит встроенной авторизации, редактора, облака, аналитики или AI. Инструкция по ручной загрузке доступна в интерфейсе. Проекты схемы 2 из архивной версии с редактором не поддерживаются.
